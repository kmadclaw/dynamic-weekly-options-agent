Krish's trading-agent operating brief

Dynamic Weekly Options Agent

A small-account, risk-gated weekly options agent that scans liquid names after the first 30 minutes, watches underlying setups, dynamically selects the best live option contract under $1, and now manages exits autonomously for profit booking and risk control using Alpaca.

Strategy in one sentence

Every trading day after 10:00 AM ET, scan a liquid 68-symbol universe, rank the top directional setups, wait for the underlying trigger, buy one qualifying weekly option contract with ask ≤ $1.00, then autonomously sell-to-close when profit or risk rules trigger.

Current live rules

  • No new entries before 10:00 AM ET.
  • If no active position/order: agent may enter autonomously.
  • If a held option hits profit/target or stop/risk: agent may sell-to-close autonomously.
  • If any active position/order exists: no additional entry is placed.
  • Executor stays silent unless it submits/fills/closes or emits a status alert.

Daily workflow

WaitIgnore first 30 minutes after open to avoid noisy fakeouts.
ScanAt/after 10:00 ET, scan 68 liquid option underlyings with 3-month daily technicals.
RankBuild top 10 BUY/SELL setups from trend, momentum, RSI, DMI/ADX, Bollinger, and levels.
TriggerWatch underlying price zones; do not pre-commit to one fixed option contract.
SelectAt trigger time, pull live option chain and choose the best weekly contract under $1.
ManageOnce filled, monitor option P/L and underlying target/stop; book profit or cut risk automatically with limit sell-to-close orders.

Entry filters

  • Underlying setup is active in the daily top-10 list.
  • Correct direction: call for bullish, put for bearish.
  • Weekly option ask is ≤ $1.00.
  • Bid/ask spread is acceptable.
  • Open interest / volume are adequate.
  • Delta target roughly 0.12–0.35.
  • Strike is aligned with the technical target and OTM profile.

Risk controls

  • Buy-to-open entries keep theoretical max loss to premium paid.
  • Hard max debit: $100 per 1-lot contract, because ask ≤ $1.00.
  • Profit booking: sell-to-close around +45–50% or when the underlying target hits.
  • Risk exit: sell-to-close around -35% or when underlying invalidation/EMA stop hits.
  • Autonomous exits are now approved by standing rule; still limit orders only, never market orders.
  • At stop boundaries, Alpaca position mark/P&L is used as a fallback when quote mid is stale or wide.

Autonomy model as of Aug 14, 2026

  • Entries: autonomous only when broker has no open option position/order and the selected contract passes all gates.
  • Exits: autonomous sell-to-close is authorized for profit booking and risk/stop exits; Krish does not need to approve each sale.
  • Order type: options use limit orders only. Sell limits are placed near the live bid/mark for realistic protective fills.
  • Status: every submitted, filled, closed, or risk/profit action is emitted back to Krish; no-trigger runs stay silent.
  • Guardrails unchanged: one-position cap, max $1 ask, spread/liquidity/delta filters, exact-contract wash guard, and no new entries in the first 30 minutes.

Wash-sale guard

The current practical guard follows Krish's preference and trading experience: after a loss/risk exit, block re-entry into the exact same option contract for 31 days.

Different strike, expiry, or option type on the same underlying remains eligible if it passes the setup and liquidity filters. After a trade closes, the agent re-arms for different contracts while preserving the exact-contract block. This is an operational trading guard, not tax advice.

Why this universe

  • Highly traded weekly options relative to small-account constraints.
  • Names move enough for low-premium contracts to matter.
  • Blend of broad-market ETFs, mega-cap tech, AI infrastructure, semis, high-beta momentum, and macro/sector anchors.
  • Large enough to avoid being stuck if one ticker is blocked or inactive, but still small enough for fast deterministic scanning.

Active automation

  • Daily dynamic weekly option setup refresh: builds top-10 setup list after 10:00 ET.
  • Dynamic weekly option setup executor: checks every minute, selects live contract at trigger time, enters only if all gates pass, and now exits automatically on profit/stop rules.
  • 15m open position updates: posts concise status only while the market is open.
